Rotinamente - Mock UI

Arquivos criados:

- lib/main.dart
- lib/pages/alarm_routine_page.dart
- lib/pages/rewards_page.dart

Como rodar (assumindo Flutter instalado):

1. Abra o diretório `rotinamente-flutter`.
2. Rode:

```bash
flutter pub get
flutter run
```

Observações:

- O app usa Material 3 (`useMaterial3: true`) e dados mockados em `StatefulWidget`s.
- O botão "+" na tela de Rotinas adiciona um alarme simulado.
